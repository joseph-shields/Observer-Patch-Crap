# Holographic closure: why a twelve-point screen is not enough

A bare finite carrier is not a boundary quantum theory. A physically meaningful holographic reconstruction is typed schematically as:

```text
Screen -> physically grounded BoundaryQFT -> dictionary -> BulkTheory -> calibrated readouts
```

HKLL is downstream of a specified boundary theory; it is not a `Screen -> BulkTheory` function.

Place twelve qubits on one icosahedral graph and compare `H0 = 0` with `HJ = J sum_(edge ij) Zi Zj`, `J != 0`. The same ports, edges, faces and incidence support different spectra, dynamics and correlators. Hence bare incidence does not select boundary dynamics.

If `U : BoundaryTheory -> BareScreen` and `H : BoundaryTheory -> BulkTheory` satisfy `U(B1)=U(B2)` but `H(B1)!=H(B2)`, no `Hhat : BareScreen -> BulkTheory` can satisfy `H = Hhat o U`.

The critique is not that HKLL establishes ontology. It is that a bare twelve-point drawing does not supply HKLL's input object. A later physical boundary theory and valid dictionary would be additional load-bearing structure, not consequences of bare screen incidence or consensus alone.
