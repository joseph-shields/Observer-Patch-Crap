# Private evidence-vault instructions

Do not place unredacted messages, personal identifiers or source originals in the public repository.

Privately preserve:

1. complete message exports with timestamps and attachment metadata;
2. exact files transmitted, with SHA-256 hashes;
3. read-only copies of public commits and diffs at cited hashes;
4. publication pages, repository releases and external timestamp records;
5. AI-context evidence where lawfully available;
6. a signed chronology describing who had access to what and when.

A file hash proves identity, not delivery time or subjective intent. Access evidence and chronology must be preserved separately. Amendments should be issued as new dated versions rather than overwriting earlier custody packages.
