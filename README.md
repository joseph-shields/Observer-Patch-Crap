## Central technical result

Let `Tsrc` be a satisfiable source theory. Let `R` be an external relation meaning that a source model is physically realized. If `Tsrc` does not constrain `R`, the same source model admits an expansion with `R = empty`. Therefore:

```text
source satisfaction
    does not entail
physical instantiation.
```

Adding more predicates, consensus rules, fixed points, entropy optimizers or source-only theorems does not change this. Formal annotation is not an ontological creation operator.

A bare carrier does not determine a boundary observable algebra, code subspace, Hamiltonian, correlations, calibration or holographic dictionary. ```text


## Theorem volume
