# The Mr Tickle Screen reductio

Assume for contradiction that satisfaction of a source-only screen theory `T_S` establishes that the screen is physically instantiated. Replace only the pictorial presentation by an original long-armed cartoon schematic carrying the same protected twelve-port source model. Every source-language theorem remains unchanged. If source satisfaction entailed physical instantiation, the cartoon presentation would inherit it.

Formal annotation, agreement maps, fixed points and arbitrarily many theorems do not cause a cartoon to become a physical holographic boundary. The information used to reject that conclusion is external to the shared source description. Therefore `T_S` does not entail external physical instantiation.

The cartoon is deliberately absurd so that the type error cannot hide behind scientific vocabulary. It can carry rigorous mathematics; rigorous mathematics about a representation is still not an ontological creation operator.
