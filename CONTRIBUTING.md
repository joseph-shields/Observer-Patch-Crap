# Contributing

Contributions must target a checkable object: a theorem statement, witness, commit date, file hash, role coding, weight, dependency edge or source citation.

Accepted contributions include countermodels, Lean improvements, exact corrections, dated contrary evidence, better independent-ancestry documentation and sensitivity analyses.

Rejected contributions include insults, harassment, unsupported allegations, doxxing, private-message publication, motive speculation and attempts to treat a similarity score as a legal verdict.

Corrections should identify the exact file/row and provide a reproducible replacement.
